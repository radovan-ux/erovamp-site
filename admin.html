How to Use This Admin Panel
Guide
1

Sign In & Access

Log in using your authorized Google account. Only the registered admin email can access the console. If you see "Access Denied", your email is not registered as an administrator.

🔐 Authentication
2

Navigate Using the Sidebar

The left sidebar lists all content sections. Click a section name to open its editor. Sections marked with 🔒 are locked and will be unlocked in future updates. Currently, About Me is fully editable.

🗂 Navigation
3

Edit the About Me Section

Inside the About Me editor, you can change the main headline, the description paragraph, upload a new photo, and control the image display size using the slider or width/height inputs. A live preview updates as you adjust settings.

✏️ Content Editing
4

Upload & Resize the About Photo

Click or drag an image into the upload zone. Use the Width slider to control how large the image appears on the live site. Select an Object Fit preset to control how the photo fills its container. The preview updates instantly.

🖼 Image Controls
5

Save & Publish Changes

Click Publish Changes to save your edits. This writes your content (text, image URL, and size settings) directly to Firebase Firestore. The changes become live on the website immediately after saving.

☁️ Firebase Sync
6

How Firebase Sync Works

This admin panel stores all content in a Firebase Firestore cloud database. The live website (index.html) reads from the same database on every page load — so any changes you publish here appear on the site automatically, without re-deploying any files.

🔁 Live Sync
7

Switch Light / Dark Mode

Toggle the switch in the top-right navbar to switch between Light Mode (white/navy, ideal for daylight) and Dark Mode (deep navy/indigo, easier on the eyes at night). Your preference is saved automatically.
